# フォント下限引き上げ + 文言修正 (灯る / お席非表示)

## 方針

ユーザーレビューで「文字が小さい」「灯ともるは冗長」「お席のご案内は機能未定」との指摘。読みやすさと文言を整える。

調査の結果、最小フォントは **9px**（在席の刻チャートの時刻ラベル 1 箇所）、次いで **10px が 21 箇所・11px が 21 箇所** と、9〜11px 帯が小ささの主因だった。

## 範囲

### 1. フォント下限 12px + 全体底上げ

`apps/web/src/app/(app)` 配下 18 ファイルに一括適用（`fontSize: N` / `text-[Npx]` / `text-xs`）:

| 旧 | 新 |
| --- | --- |
| 9 / 10 / 11 | 12（下限） |
| 12 / 13 | 14 |
| 14 / 15 | 16 |
| 16 | 18 |
| 17 / 18 / 22 / 24 / 26 / 32 / 34 | 据置（見出し・大ニックネーム・統計数字） |

- `globals.css` の body base も 17 → 18px
- 単一パスの正規表現置換（descending cascade なし）で、原値を一度だけ写像。下限が 12px に揃う

### 2. 文言: 「灯ともる」→「灯る」

「灯る」(ともる) で送り仮名は足り、「灯ともる」は冗長。5 箇所を修正:
- 己プロフィール status / 灯る の見え方（編集）
- 他者プロフィール status
- DM スレッド header status
- 軒先 RightRail「灯 る 羊」

### 3. お席のご案内 を非表示

`timeline/_components/right-rail.tsx` の `お席のご案内`（hashtag 風 placeholder）は spec で tag 機能が未採用・未定のため非表示に。`SEATS_PLACEHOLDER` const も削除。`listSeats()` use case 実装時に復活する旨コメントを残す。

## 設計判断

- **px は rem でなく絶対値が大半** → `zoom` での全体スケールは `h-[calc(100vh-64px)]` 等の full-height sticky 板が vh×zoom で溢れるため不可。値ごとの写像で「下限 12px」を機械的に担保する方が安全
- **見出し・統計数字は据置** → 既に十分大きく、底上げ対象は読み面と小ラベルに限定
- **お席は削除でなく非表示+コメント** → 将来 listSeats 実装時の復活を見越し、意図を残す

## 検証

- `pnpm -F @me-me-en/web typecheck`: 緑
- ローカル dev server で timeline / chats / 己 / 他者プロフィールを目視:
  - お席のご案内 が消えていること
  - 「灯る羊」「灯る · 今宵 在席」表記
  - 本文・ニックネーム・ラベルが一段大きく、下限 12px、崩れなし

## 残課題

- named Tailwind size (text-sm / text-base / text-lg) を使う edit フォーム等は今回対象外（いずれも ≥14px のため floor は満たす）
